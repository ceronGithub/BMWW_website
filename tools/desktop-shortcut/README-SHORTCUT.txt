BMWW Desktop Shortcut (v22)
===========================
PARA SAAN: gumawa ng shortcut na "BMWW" sa Desktop na nagbubukas ng index.html sa Chrome (o Edge).

BAKIT HINDI GUMAGANA ANG SARILING SHORTCUT / KOPYA NG index.html
- Ang index.html ay nangangailangan ng mga folder sa tabi nito (css, js, pages, components). Kapag index.html lang ang kinopya sa Desktop, hindi mag-lo-load nang maayos. HUWAG kopyahin ang index.html; shortcut lang ang ilagay sa Desktop.
- Ang karaniwang shortcut ay binubuksan ng default browser; kailangan ng BMWW ang Chrome o Edge (folder access).

PAANO
1. I-extract ang BUONG zip sa permanenteng folder (hal. Documents\BMWW-WEB). Huwag buksan mula sa loob ng zip.
2. Buksan ang folder tools\desktop-shortcut at i-double click ang create-desktop-shortcut.bat.
3. Dapat lumabas ang "TAPOS" at may bagong icon na BMWW sa Desktop. I-double click ito.
4. Kung inilipat mo ang project folder, patakbuhin ulit ang .bat.

KUNG HINDI PA RIN GUMANA: kunan ng screenshot ang nakikita mo (o ang mensahe sa itim na window) at ipakita.
