INSTRUCTIONS v3.4 (File Watcher: kasama na ang Data source 1 na may na-modify na file; may Install at Paano i-uninstall sa Settings)
1. Mag-Save As muna ng kopya ng buong website folder (backup). I-unzip ang BMWW_website_v3.2.zip sa BAGONG folder, o ipalit ang 3 binagong file at ilagay ang 2 bagong file (tingnan ang listahan sa README, v3.2).
2. Buksan ang index.html sa Chrome o Edge (double-click), tapos Ctrl+F5. Pumunta sa Settings.
3. TEST STEPS:
   - Wala pang Saving path: DAPAT may card na "File Watcher (optional)", sarado ang button na Install File Watcher, at may note na piliin muna ang Saving path.
   - Piliin ang Saving path (BMWW): DAPAT bumukas ang button.
   - Pindutin ang Install File Watcher: DAPAT lumabas ang babala (pulang kahon, warning sign) at ang tick na "Naiintindihan ko". DAPAT HINDI pa makita ang mga hakbang.
   - I-tick: DAPAT lumabas ang mga hakbang at ang path. Ang path ay dapat ang folder ng website + \tools\file-watcher.
   - Pindutin ang Copy path, buksan ang File Explorer (Win + E), i-paste sa address bar: DAPAT bumukas ang folder na may install-watcher.bat.
   - Pindutin ang Isara at buksan ulit: DAPAT naka-untick at nakatago ulit ang mga hakbang.
   - Pumunta sa ibang page at bumalik sa Settings: DAPAT iisa lang ang card.
   - DAPAT HINDI mangyari: may program na tumakbo nang kusa; error sa console; nagbago ang Save settings, mga path at machine name.
   - Paano i-uninstall: DAPAT laging bukas ang button (kahit wala pang Saving path). Pindutin: DAPAT lumabas ang hakbang (walang babala, walang tick), ang path, at ang manual na paraan. Kapag binuksan ang Install, DAPAT sumara ang Uninstall (isang panel lang ang bukas).
   - Totoong uninstall (kung naka-install ang watcher): i-double-click ang uninstall-watcher.bat. DAPAT lumabas ang "Natanggal ang shortcut sa Startup." at "TAPOS.". Win + R > shell:startup: DAPAT wala na ang "BMWW File Watcher". Pagkatapos mag-restart, DAPAT HINDI na bumubukas ang website kapag may bagong file sa CLO1A.
   - DATA SOURCE 1 SA WATCHER: buksan ang tools\\file-watcher\\watcher-config.txt (Notepad), ilagay sa ModifiedWatchPaths ang full path ng Data source 1 (kopyahin sa Settings), i-save, tapos i-double-click ang install-watcher.bat ulit. Pang-test: run-watcher-visible.bat.
     * Gumawa ng bagong file sa Data source 1: DAPAT lumabas ang "Bagong item" at bumukas ang website (Search Files).
     * I-save ulit ang isang umiiral na file doon (hal. ang master CSV): DAPAT lumabas ang "Na-modify na file" nang isang beses lang kada save, at bumukas ang website (kung lampas na ang cooldown na 120 segundo at wala pang bukas na website).
     * I-save ulit ang file sa CLO1A: DAPAT HINDI lumabas ang "Na-modify na file" (bago lang ang binibilang doon).
     * Ang ~$ at .tmp na file: DAPAT HINDI bumilang.
     * Kung blangko ang ModifiedWatchPaths: DAPAT gumana pa rin ang CLO1A at CLO1A1 tulad ng dati.
   - Ang install-watcher.bat ay ikaw mismo ang magpapatakbo (README-WATCHER.txt). Sa company laptop, ipaalam muna sa IT.
   - Ibalik sa akin kung mali ang ipinakitang path (lalo na kung OneDrive, network drive o http ang pinagbubukasan).
   - Hindi pa ito nasubukan sa totoong Chrome/Edge ng gumawa (jsdom lang para sa Settings, 26 test; ang watcher ay nasubukan lang sa PowerShell 7 sa Linux); ang unang test ay sa device mo.
