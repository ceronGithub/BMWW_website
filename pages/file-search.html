Search Files

Hanapin ang file sa CLO1A at CLO1A1 ayon sa pangalan, saklaw ng petsa, o pinakabago. Basa lang ang paghahanap; walang binabago sa mga folder.

Saan hahanapin

Ang CLO1A at CLO1A1 ay Data source 2 at 3 sa Settings. Buksan ang Settings

    Search

    Search by name

    Walang * o ?: hahanapin ang pangalang may ganitong salita. May * o ?: wildcard.

    Search by range date

    Ang petsa ng file (last modified) ang gamit.

    Send to

    Kokopyahin ang napiling file. Kung may kapangalan na sa destination, tatanungin ka kung papalitan. Ang tala ng naipadala ay isusulat sa Saving path (logs\send-log.txt).

    Hindi makukuha ng browser ang path mula sa folder. I-type ang path at piliin din ang folder para magamit.

    Result

    Status: PENDING = hindi pa naipapadala | SENT = naipadala na | REPLACED = napalitan ang kapangalan | EXISTS = nasa destination na (hindi pinalitan) | FAILED = hindi naipadala
