Settings

Itakda ang pangalan ng machine at ang mga folder na gagamitin ng BM Analyzer.

Machine name

Mga path

Piliin ang bawat folder, tapos ilagay ang full path nito (kailangan ito pagkatapos mapili ang folder). Hindi maibibigay ng browser ang buong path, pangalan lang ng folder. Pindutin ang Save settings para ma-save ang mga pagbabago.

    Mga .bat tool (install at uninstall)

    Nasa folder na tools ng BMWW ang lahat ng ito. I-double-click ang .bat sa File Explorer; hindi kailangan ng Administrator. Dapat lumabas ang salitang TAPOS sa dulo. Kapag wala, kunan ng screenshot ang itim na window bago pindutin ang anumang key.

    • Ilagay ang BUONG BMWW folder sa permanenteng lokal na folder (hal. C:\BMWW_App\), hindi sa ZIP, Downloads o network drive. Kapag inilipat, patakbuhin ulit ang install .bat.
    • Galing sa ZIP? Right-click ang ZIP > Properties > Unblock, bago i-extract.
    • Hindi pa nasubukan sa totoong Windows ang mga bagong .bat. Ang unang test ay sa PC mo.
    Ongoing Monitor BAGO Sender PC lang

    Para saan: tuloy-tuloy na binabasa ang Data source 1, 2, 3 kahit SARADO ang website. Isinusulat ang status ng machine (ongoing / done / idle) sa <Server path>\queue\<machine>.json para ma-update ang Dashboard ng LEAD PC, at binubuksan ang website sa Dashboard kapag may pagbabago. Basa lang ang Data source.

    I-install (isang beses)

    1. Sa Settings na ito: ilagay at i-Save ang Machine name, Saving path, Server path at Data source 1, 2, 3 (may Full path ang bawat isa).
    2. Buksan sa Notepad ang tools\ongoing-monitor\ongoing-monitor-config.txt at ilagay ang SavingPath= (hal. SavingPath=C:\Users\Name\Desktop\BMWW). Tingnan din ang Browser at Page.
    3. I-double-click ang install-ongoing-monitor.bat. Gagawa ito ng shortcut sa Startup at tatakbo agad nang tago; tatakbo na ito tuwing mag-log in sa Windows.
    4. Kapag nagbago ang config: patakbuhin ulit ang install .bat.

    Pang-test

    1. Kung naka-install na, i-uninstall muna (para hindi dalawa ang tumatakbo).
    2. I-double-click ang run-ongoing-monitor.bat. Dapat lumabas ang "Settings: <machine> (user-input)".
    3. Isara ang website, tapos mag-save o gumawa ng file sa Data source 1, 2 o 3. Dapat lumabas ang "Pagbabago sa sourceN" at bumukas ang website sa Dashboard.
    4. Isara ang console window para itigil.

    I-uninstall

    I-double-click ang uninstall-ongoing-monitor.bat. Binubura nito ang shortcut sa Startup at itinitigil ang monitor. Hindi nito binubura ang project folder, config, ongoing-monitor.log o ang mga status file sa Server path\queue.

    Local launcher BAGO

    Para saan: binubuksan ang BMWW sa http://localhost:8765/index.html (hindi sa double-click na file://). Sa localhost, puwedeng piliin ng Chrome/Edge ang "Allow on every visit" para hindi na magtanong ng permission ng folder. Maliit na local server ito (127.0.0.1 lang, hindi abot ng ibang PC).

    Patakbuhin (walang install)

    1. I-double-click ang tools\local-launcher\start-bmww-local.bat. Lalabas ang itim na window na "BMWW local server - HUWAG ISARA".
    2. Magbubukas ang Chrome (o Edge) sa localhost. Sa Settings, piliin ulit ang BMWW, Server path at Data source (isang beses lang; ibang "address" ang localhost kaysa sa file://).
    3. Kapag nagtanong ang browser ng edit access, piliin ang "Allow on every visit" kung nandoon.
    4. Pang-araw-araw: right-click ang .bat > Send to > Desktop, o ilagay ang shortcut sa Startup (Win+R > shell:startup).
    5. Para gumana sa Ongoing Monitor: ilagay sa config ang WebsiteUrl=http://localhost:8765/index.html, tapos patakbuhin ulit ang install-ongoing-monitor.bat.

    Itigil at i-uninstall (walang uninstall .bat)

    1. Isara ang itim na window (o Ctrl+C). Tanggalin ang shortcut sa Desktop o Startup.
    2. Kung kusa itong sinimulan nang tago ng Ongoing Monitor: buksan ang PowerShell (Win+X) at i-paste ito, tapos burahin ang WebsiteUrl sa config at i-install ulit ang monitor: Get-CimInstance Win32_Process -Filter "Name = 'powershell.exe'" | Where-Object { $_.CommandLine -like '*start-bmww-local.ps1*' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }

    Limitasyon: port 8765 lang; kailangan ng Chrome/Edge na bago (Chrome 122 pataas para sa Allow on every visit).

    Check templates BAGO Developer

    Para saan: sinusuri kung magkapareho ang pages\*.html at ang kopya nito sa js\templates\*.template.js. Kapag DRIFT, maaaring iba ang lumalabas sa double-click na bersyon. Basa lang; walang binabago.

    Patakbuhin (walang install)

    1. Kailangan ng Node.js (nodejs.org). Kung wala, lalabas ang mensahe at hihinto ito.
    2. I-double-click ang tools\check-templates\run-check-templates.bat. Lalabas ang MATCH o DRIFT kada page. Kapag may DRIFT, ipakita ang output.

    I-uninstall

    Wala; walang naiiwan sa PC.

    File Watcher

    Para saan: kusang binubuksan ang website (Search Files) kapag may bagong file o folder sa CLO1A o CLO1A1. Tumatakbo kahit sarado ang browser. Basa lang ang mga folder.

    I-install

    1. Buksan ang tools\file-watcher\watcher-config.txt; tingnan ang WatchPaths, ModifiedWatchPaths (full path ng Data source 1, blangko = hindi gagamitin) at Browser.
    2. I-double-click ang install-watcher.bat. Gagawa ng shortcut sa Startup at tatakbo agad nang tago. Kapag nagbago ang config, patakbuhin ulit.

    Pang-test

    I-double-click ang run-watcher-visible.bat, gumawa ng bagong file sa CLO1A: dapat lumabas ang "Bagong item" at bumukas ang website. Isara ang window para itigil. Log: watcher.log.

    I-uninstall

    I-double-click ang uninstall-watcher.bat.

    Open handler

    Para saan: para gumana ang "Open latest repeatability file" at "Open latest correl file" (binubuksan sa Excel; hindi kaya ng website mismo). Tumatakbo lang ito kapag pinindot ang button. Nagsusulat sa HKCU\Software\Classes\bmww-open (user mo lang); sa company laptop, ipaalam muna sa IT.

    I-install

    1. I-double-click ang tools\open-handler\install-open-handler.bat. Dapat lumabas ang "TAPOS: naka-install ang bmww-open".
    2. Siguraduhing FULL PATH ang Saving path sa itaas (hal. C:\BMWW).
    3. Sa unang pindot ng Open latest ... file, i-tick ang "Always allow" at pindutin ang Open.

    I-uninstall

    I-double-click ang uninstall-open-handler.bat. Log: open-handler.log.

    Desktop shortcut

    Para saan: gumagawa ng shortcut na "BMWW" sa Desktop na nagbubukas ng index.html sa Chrome (o Edge). Huwag kopyahin ang index.html sa Desktop; shortcut lang.

    I-install

    I-double-click ang tools\desktop-shortcut\create-desktop-shortcut.bat. Dapat lumabas ang "TAPOS" at may bagong icon na BMWW sa Desktop. Kapag inilipat ang project folder, patakbuhin ulit.

    I-uninstall

    Burahin ang BMWW.lnk sa Desktop. Walang ibang naiwan.

    May pagbabago na hindi pa na-save. Pindutin ang Save settings para ma-save.
